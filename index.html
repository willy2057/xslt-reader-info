XSLT Reader隱私權政策

讓舊 XML 文件繼續閱讀。

在缺少原生 XSLT 的 Chrome 中，使用本機引擎套用文件原有的 XSLT 1.0 樣式表。支援範圍包含本機文件、網站與內網，另提供逐來源啟用的設備相容模式。

試用虛構資料

先安裝 XSLT Reader，再開啟以下 XML。瀏覽器若仍使用原生 XSLT，畫面本身不足以證明擴充功能的轉換引擎已運作。

  • 辦公用品庫存報表：四筆虛構資料，示範預設靜態閱讀。
  • 設備相容模式示範：在擴充功能選單對此來源啟用相容模式並重新處理，才能使用頁面的「查看使用說明」按鈕。按鈕只切換說明，不送出資料。

使用前確認

本機 XML 需要在擴充功能詳細資料開啟「允許存取檔案網址」。一般 HTML、純 XML 及 XML＋CSS 不會被替換。原網站有嚴格 CSP、特殊登入或 IE／ActiveX 功能時，可能無法相容。

目前支援 XSLT 1.0，不支援 2.0／3.0。設備相容模式預設關閉，只對信任來源啟用；原網站程式仍可能執行其原有操作。實際設備的儲存、列印及管理員功能尚未完整驗證。

資料與聯絡

文件在本機轉換，不會上傳至開發者的轉換服務。讀取原網站及其資源仍會產生一般網路請求。資料種類、設定儲存與刪除方式請見完整隱私權政策。
