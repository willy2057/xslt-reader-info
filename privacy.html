隱私權政策

更新日期：2026 年 11 月 24 日 · 適用版本：0.2.2

XSLT Reader 用於在你的裝置上，將開啟的 XML 文件依原有 XSLT 1.0 樣式表呈現。本政策說明擴充功能如何處理文件、網站導覽資訊及本機設定。

文件內容與轉換

擴充功能會讀取需要轉換的 XML、XSL、相關依賴及轉換結果，在本機記憶體處理及顯示。文件可能含姓名、Email、地址、設備資訊或其他由文件來源提供的資料；擴充功能不另外建立通訊錄名單，也不將這些內容傳送到開發者的轉換服務。

擴充功能不主動永久保存文件內容、不提供開發者遠端文件日誌，沒有廣告、追蹤分析或遙測服務。原始 XML 檢視可能在分頁記憶體中保留快照；關閉相關分頁或停止轉換後，該用途的工作資料會釋放。瀏覽器本身的快取、歷程、記憶體管理、下載，以及原網站的儲存行為，仍由瀏覽器和原網站管理。

連線到原網站

本機轉換不表示完全不連網。網路文件的靜態轉換會讀取原 XML、同來源 XSL 與轉換依賴。請求可由瀏覽器依正常規則帶入原網站的登入 Cookie；本擴充功能沒有 cookies 權限，不另外從 Cookie 或 Authorization 標頭擷取憑證，也不代替使用者登入。不過，原始 URL 或文件本身可能含密碼、登入或一次性權杖，這些內容會隨文件處理或下述導覽配對流程暫時保留於本機，不另行上傳至開發者。

轉換結果所引用的 CSS、圖片、字型及其他允許的顯示資源，可能向文件指定的網站提出請求。若使用 HTTP 設備，該連線本身沒有 HTTPS 的傳輸加密；擴充功能不會替原網站升級加密或繞過瀏覽器安全限制。

可選的設備相容模式

相容模式預設關閉，必須由你針對完整來源（協定、主機與連接埠）明確啟用。啟用後，擴充功能直接處理這次導覽收到的原始 XML，並在原網頁保留其 JavaScript、表單與框架。

原網站程式以網站本身的權限執行，不取得擴充功能 API 特權；它仍可能存取該網站資料、依網站規則發出網路請求，以及執行你觸發的網站操作。這些網站行為由原網站控制，受其政策及瀏覽器限制。請只對你信任的來源啟用，並避免同時使用多套 XML 轉換擴充功能。

暫時的導覽資訊

為了避免將 POST 或一次性回應錯誤重新讀取，擴充功能被動觀察頂層 HTTP／HTTPS 導覽的 URL、請求方法、時間、請求識別與文件識別資料。這包括一般 HTML 頁面的頂層導覽中繼資料；普通 HTML 內文不會被作為 XML 轉換內容讀取。擴充功能不請求網路 request body，也不建立或上傳完整瀏覽歷程資料庫。

CSP 回應標頭只用來判斷是否已知及是否限制相容模式腳本，保存的是布林判定，不保存標頭原文。分頁配對、方法、URL、安全政策判定與暫停狀態可能暫存於 chrome.storage.session；URL 保留查詢參數，因此其中若含權杖也會隨 URL 暫存。關閉分頁會清理該分頁的已保存識別資訊，瀏覽器工作階段結束後由 Chrome 清理 session 儲存。

長期保存在裝置上的設定

chrome.storage.local 只保存自動處理開關與你選取的相容模式來源清單。來源清單可能包含內網設備的主機名稱、IP 或連接埠，不包含 XML／XSL 內文。設定不會使用 Chrome Storage Sync 同步至開發者或其他裝置。

用途、分享與有限使用

上述資料僅用於文件呈現、讀取原文件資源、提供你啟用的相容功能，以及避免錯誤重新讀取來源。開發者不出售使用者資料，不將資料用於廣告、使用者側寫、信用評估或借貸決策，也不提供人工閱覽使用者文件的後台。

XSLT Reader 對使用者資料的使用及轉移遵守 Chrome 線上應用程式商店使用者資料政策，包含 Limited Use（有限使用）要求。向原網站與文件指定資源提出的必要請求，以及你在相容頁觸發的原網站操作，屬上述已揭露功能；本擴充功能不額外將文件傳送給開發者或資料分析服務。

你的選擇與刪除

  • 可在擴充功能選單暫停自動處理，並重新載入頁面使設定生效。
  • 可取消特定來源的相容模式；對原本以 GET 開啟的頁面重新處理，或關閉頁面再重新開啟。取消設定不會立即終止目前頁面已執行的原網站腳本。
  • 可透過 Chrome 擴充功能設定限制網站存取或關閉檔案網址權限。本機轉換依賴限定在來源 XML 所在目錄及子目錄內；不掃描或列舉磁碟文件。
  • 可關閉相關分頁，或移除擴充功能以清除它的本機設定。這不會刪除原網站資料、設備設定、瀏覽器快取或下載檔案。

政策網頁與外部服務

本頁沒有分析腳本、外部字型或追蹤圖片。若透過 GitHub Pages 等服務託管，服務提供者仍可能依自身政策處理訪客 IP 等網站存取資訊；這與擴充功能的本機文件轉換分開運作。使用者主動聯絡發布者時所提供的 Email 與訊息，僅用於回覆該次詢問，不會自動附帶 XML 文件。

政策更新

如果功能或資料處理方式改變，我們會更新本頁與商店揭露資訊，並在本頁標明日期。需要額外權限時，依 Chrome 的機制告知使用者。
