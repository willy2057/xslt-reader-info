# XSLT Reader：政策與示範網站

此儲存庫僅提供 XSLT Reader 的隱私權政策、使用說明及虛構 XML／XSLT 1.0 示範文件，不包含完整擴充功能或真實設備資料。

- `index.html`：使用說明與示範入口。
- `privacy.html`：隱私權政策草稿。發布者名稱與公開聯絡方式仍待填寫，正式提交 Chrome 商店審查前需補齊。
- `demo/report.xml`：四筆虛構辦公用品資料，供靜態閱讀測試。
- `demo/device.xml`：虛構設備畫面。相容模式的原網站按鈕只切換說明，不儲存或送出資料。
- `.nojekyll`：讓 GitHub Pages 直接提供靜態檔案，保留 XML、XSL 與 JavaScript 原文。

GitHub Pages 的發布來源為 `main` 分支的根目錄。啟用部署後再確認公開頁面可用；此儲存庫不會自動提交或發布 Chrome 商店項目。
